# Cytosine-converted Read Sorting
In this subdirectory, we execute different read sorting algorithms (Xengsort, bamcmp and XenofilteR) to distinguish between human and mouse reads in *in silico* mixtures.


## Xengsort 
Xengsort is a k-mer–based classifier designed to separate sequencing reads originating from different species in xenograft experiments.
Instead of aligning reads, it builds a k-mer index from the host and graft reference genomes and assigns each read to categories such as **host**, **graft**, **both**, **ambiguous**, **both** or **neither** based on the species-specific k-mers it contains.

### Xengsort index construction

The following command builds a k-mer index for species classification:

```bash
xengsort index \
  --index "$INDEX_PATH" \
  -H "$GENOME_MOUSE_PATH" \
  -G "$GENOME_HUMAN_PATH" \
  -n 9_000_000_000 \
  --bisulfite \
  -k 29
```

#### Parameters

- `--index "$INDEX_PATH":`
    Output path where the generated Xengsort index will be stored.

- `-H "$GENOME_MOUSE_PATH":`
    Reference genome of the host species (mouse).

- `-G "$GENOME_HUMAN_PATH":`
    Reference genome of the graft species (human).

- `-n 9_000_000_000:`
    Size of the hash table used for storing k-mers. A large value is specified to accommodate the combined genome size and reduce hash collisions.

- `--bisulfite:`
    Enables bisulfite-aware indexing so that k-mers reflect C→T / G→A conversions typical of bisulfite sequencing.

- `-k 29:`
    Length of k-mers used for classification. A k-mer size of 29 provides a good balance between species specificity and tolerance to sequencing errors.

### Xengsort sorting
```bash
xengsort classify \
  --index "$INDEX_PATH" \
  --fastq "$FILE_R1" \
  --pairs "$FILE_R2" \
  --prefix "$OUT_PREFIX" \
  --mode count \
  --threads "$THREADS"
```

This step processes paired-end FASTQ files and assigns reads to species categories based on species-specific k-mers stored in the Xengsort index. Each read pair is classified as **host**, **graft**, **both**, **ambiguous**, or **neither**.

### Parameters

- `--index "$INDEX_PATH"`  
  Path to the previously generated Xengsort k-mer index.

- `--fastq "$FILE_R1"`  
  FASTQ file containing **read 1** of the paired-end sequencing data.

- `--pairs "$FILE_R2"`  
  FASTQ file containing **read 2** of the paired-end sequencing data.

- `--prefix "$OUT_PREFIX"`  
  Prefix used for naming output files generated by the classification step.

- `--mode count`  
  Classifies the read based on the number of kkk-mers that belong to host or graft

- `--threads "$THREADS"`  
  Number of CPU threads used for parallel processing.

## bamcmp
bamcmp is an alignment-based read sorting tool that extracts alignment or mapping quality scores from a previous alignment of a human/mouse mixture against the human and mouse reference genomes. Paired-end reads are classified to be *humanOnly*, *humanBetter* or *mouseOnly* and *mouseBetter* based on their mapping qualities.

### bamcmp alignment-based sorting
Bamcmp (v2.2) species assignment was performed with name-based comparison (-n) and match scoring mode (-s match).  For performance evaluation, reads classified as human-only or human-better were considered human, whereas reads classified as mouse-only or mouse-better were considered non-human.

## XenofilteR
XenofilteR is also an alignemnt-based read sorting tool that calculates edit distances of each read against the human and mouse reference genomes. Paired-end reads are classified to be *human* or else discarded.

### XenofilteR alignment-based sorting
XenofilteR was run in R (v1.6) using the XenofilteR() function with default parameters, except for MM_threshold = 8 to increase performance for longer (100 and 150 bp) paired-end reads.
