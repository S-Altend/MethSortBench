# Evaluation of Read Sorting Results

In this directory, we evaluated the read sorting results from **bamcmp**, **XenofilteR**, **Xengsort** and **ICRG** generated by [03_read_sorting](../03_read_sorting/) and [04_icrg](../04_icrg/).

Since every tool generated their own individual output files, we wrote an 'evaluation script' for every algorithm:

| Script                                                       | Sorting Files                                                   |
| ------------------------------------------------------------ | --------------------------------------------------------------- |
| [05.1_xengsort_evaluate.sh](./05.1_xengsort_evaluate.sh)     | FASTQ: *host* (mouse), *graft* (human), *ambiguous*, *both*, *neither* |
| [05.2_icrg_evaluate.sh](./05.2_icrg_evaluate.sh)             | BAM: chr -> human, m.chr --> mouse                            |
| [05.3_bamcmp_evaluate.sh](./05.3_bamcmp_evaluate.sh)         | BAM: *humanBetter*, *humanOnly*, *mouseBetter*, *mouseOnly*          |
| [05.4_xenofilter_evaluate.sh](./05.4_xenofilter_evaluate.sh) | BAM: *filtered* (human)                                              |

## Ground Truth Read Association
During *in silico* mixing of WGBS reads, we annotated reads in the read header as `mouse_` or `human_`. This information can be extracted after alignment and resulting metrics are calculated in [07_visualization](../07_visualization/).
- True Positives (TP): Human reads sorted to human.
- False Positive (FP): Non-human reads sorted to human.
- True Negatives (TN): Non-human reads sorted to non-human.
- False Negatives (FN): Human reads sorted to non-human.

## bamcmp Evaluation
bamcmp read sorting yields 4 sorted .bam files: *humanBetter*, *humanOnly*, *mouseBetter* and *mouseOnly*.
Since the tool was developed for Whole Genome Sequencing, almost all bisulfite-converted reads were ambiguously classified as either *humanBetter* or *mouseBetter*. Therefore, we evaluated these ambiguous classes as human and non-human to calculate TP, FP, TN and FN.


## XenofilteR Evaluation
XenofilteR read sorting yields 1 sorted .bam file, which only contains the as human classified reads. From this result, we can directly calculate TP and FP. TN and FN are calculated based on our ground truth knowledge. 


## Xengsort Evaluation
Xengsort read sorting yields five .fastq files: *host*, *graft*, *ambiguous*, *both*, *neither*. \
TP and FP are called from *graft*, TN and FN from *host*, *ambiguous*, *both*, *neither*.


## In Silico Combined Reference Genome
ICRG uses a concatenated reference genome (mouse + human), whereas mouse chromosomes are labelled as m.chr. TPs are determined by counting the number of human reads (`human_` prefix) assigned to human chromosomes. TNs are calculated by extracting non-human reads (`mouse_` prefix) that aligned to mouse chromosomes or were unmapped. FPs are non-human reads aligned to human chromosomes.
